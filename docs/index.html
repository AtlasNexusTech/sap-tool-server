🔌 Integration

Any SAP agent can call our tools — one 402 handshake, then the result.

# Step 1: Call the tool
curl -X POST https://your-server.com/tools/acedatacloud-chat \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Analyze Solana DeFi trends 2026"}'

← 402 Payment Required
{
  "amount_usdc": 0.10,
  "receiver": "45Y2ShED3GyPQEhfaPq68Z...",
  "protocol": "x402"
}

# Step 2: Pay via Solana, resend with proof
curl -X POST https://your-server.com/tools/acedatacloud-chat \
  -H "X-Payment-Signature: <solana_sig>" \
  -d '{"prompt": "Analyze Solana DeFi trends 2026"}'

← 200 OK
{
  "analysis": "Solana DeFi in 2026 shows...",
  "price_usdc": 0.10
}
